# CS224N 中文交互教程

按 Stanford CS224N《Natural Language Processing with Deep Learning》**Winter 2026** 的讲次顺序编写的中文教程。只要会高中数学就能从头学起：用到的线性代数、概率、微积分都在第 0 部分讲，每个概念都先讲直觉，再给公式，再用具体数字算一遍，并配有可以动手的交互实验。

> 这是学习者写的非官方中文教程，不是斯坦福官方材料。

## 怎么打开

1. 下载这个仓库：在 GitHub 页面点 **Code → Download ZIP** 并解压，或者 `git clone https://github.com/Nyarlathoteppppp/cs224n.git`。
2. 用浏览器（Chrome、Edge、Safari、Firefox 都可以）**直接双击打开 `index.html`**。

不需要联网，也不需要安装任何东西。网站只针对电脑屏幕优化。

## 怎么学

- **按顺序读。** 从第 0 部分开始。每章开头的“开始之前，你需要知道”列出前置知识，点链接就能跳回去；标着“补”的小节是当场补讲的基础知识。
- **每个小节回答一个问题**，顺序是：问题 → 直觉 → 定义与公式 → 算一遍 → 一句话记住。**红色加粗**的是重点句。
- **公式卡片**：点公式下面的彩色标签，看每一项是什么意思；有“下一步”按钮的，可以一步步看推导。
- **交互实验**：拖动、点击、调滑块，看数字和图怎么变。标着“课件外”的数字是为了演示编的，其余数字来自课程材料。
- **小测**：每章末尾有几道题，答完会显示解释。能不看网站、用自己的话讲清一章时，勾选页面底部的“我能不看网站，用自己的话讲清这一章”，左侧目录会记录进度。
- **笔记**：每章末尾可以写笔记，自动保存在当前浏览器里；左侧目录底部的“导出笔记与进度（Markdown）”可以把所有笔记和进度导出成一个文件。进度和笔记不会上传到任何地方，换浏览器或清除浏览器数据会丢失，记得导出。
- **作业章**（每部分最后一章）只讲每道题考什么、用到哪几章、怎么做、怎么自查，**不给答案**。
- 其他：左侧目录顶部可以搜索；顶栏有“公式速查”和“综合测验”；右上角可以调字号、切换深色；`Alt + ←` / `Alt + →` 切换上一章、下一章。

## 内容依据

- 以 CS224N Winter 2026 的官方课件、官方 notes 和作业为准；讲课顺序和比喻参考了往年同一门课的讲课录像。超出这些材料的内容都标了“课件外”。
- 仓库里**不包含**斯坦福的课件、notes 和录像。需要原始材料请去课程官网 <https://web.stanford.edu/class/cs224n/>。
- 每个数值例子都能用 `js/core/` 里的代码重新算出来，并写进了测试。

## 想自己修改或参与

```
index.html        入口页面
css/              样式
js/core/          课程里的算法（向量、softmax、word2vec、反向传播、注意力、BPE……），每个都有测试
js/ui/            页面框架：章节渲染、公式卡片、小测、术语标注
js/viz/           交互实验
data/chapters/    章节内容，一章一个文件
data/visuals.js   交互实验和视频的设计说明
tests/            测试与检查脚本
tools/            资料下载、整理脚本和给辅助模型的规格
COURSE_MAP.md     全课程的章节规划
CLAUDE.md         写作规则
```

常用命令（需要 Node.js 和 Python 3）：

```bash
node tests/core.test.js      # 核心算法测试，期望值来自课件原数
node tests/site.check.js     # 检查章节结构、链接、小测、公式渲染，以及“先用后讲”
python3 tools/serve.py       # 本地预览，http://localhost:8224 ，不缓存，适合边改边看
tools/fetch_reference.sh all # 把官方材料下载到 reference/（不进仓库）
```

写作上的约定（术语第一次出现写成“中文（English）”、不默认读者懂没学过的东西、每个数字都要能复现等）见 `CLAUDE.md`。
